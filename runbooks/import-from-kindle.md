# Runbook: Import Kindle highlights

Your highlights and notes become quotes of yours on the books they are from (ARCH.md §16 #77),
private until you mark each one to show on share pages.

## Get the file

- **A Kindle device:** plug it in and copy `documents/My Clippings.txt`. It holds every
  highlight, note and bookmark the device has made, oldest first.
- **The Kindle app:** open a book's notebook and choose *Export notebook* → email; save the
  attached HTML. One book per file.

## Import

1. **Import / export → Kindle highlights**, pick the file and the shelf new books should go on.
2. **Preview (dry run)** says how many books are already here (matched by title and author)
   and lists the ones that would be added as “Not owned” reading-log entries.
3. **Import highlights.** Each highlight becomes a quote dated when Kindle recorded it; a note
   Kindle attached at the same place becomes the quote's note. Bookmarks are ignored.

Importing the same file again adds nothing twice. Everything is yours, the signed-in member's.
Find them under **Reading → Quotes**, or on each book's page, where you can edit a quote, add a
note, or tick *Show on share pages*.

## What it never does

- Nothing is sent anywhere: the file is read in your browser.
- No quote leaves the app unless you share it, and a note never does.
