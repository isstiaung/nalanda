# Logo options — "Nalanda was a library"

Concept exploration, kept for reference. **Chosen: `option-2d-ratnodadhi-brick.svg`**
— now `public/logo.svg` (favicon, PWA icons, manifest all follow it).
Preview any file with Quick Look (space bar in Finder) or a browser. Palette is the manuscript-ledger system:
palm-leaf buff `#f6f2e7`, indigo `#35447e`, vermilion `#b93a1c`, turmeric
`#d3a02f`, lampblack `#221d14`.

| File | Concept |
|---|---|
| `option-1-pothi-stack.svg` | A bound pothi: palm-leaf pages between red-lacquered wooden covers, binding-cord hole punched through. "A book, the Indian way." |
| `option-2-ratnodadhi-tower.svg` | Ratnodadhi ("Ocean of Jewels"), Nalanda's nine-storey library tower, built from stacked manuscript leaves; jewel at the summit. Indigo ground. |
| `option-2b-ratnodadhi-paper.svg` | Same tower, paper-first colorway: indigo leaves on palm-leaf buff (ink on paper — the app's palette as you actually see it). |
| `option-2c-ratnodadhi-ink.svg` | Same tower in lampblack on buff — closest to the app's dominant text-on-paper read. |
| `option-2d-ratnodadhi-brick.svg` | Same tower in brick vermilion on buff, ink plinth — the tower as it actually stood: Nalanda's red brick, with red leading the mark the way the headstroke leads the app. |
| `option-3-manuscript-niche.svg` | An arched niche in Nalanda's brick walls stacked with rolled manuscripts seen end-on; one vermilion volume. |
| `option-4-open-leaf.svg` | A single palm leaf: ruled text, rubricated (vermilion) opening line, binding hole at the left third. |
| `option-5-lamp-of-learning.svg` | A diya burning over a manuscript leaf — the lamp-lit reading room; the flame is what a library keeps alive. |

When one is chosen: it becomes `public/logo.svg`, and the PWA icons
(`public/icons/*`) + `manifest.webmanifest` colors get regenerated to match
(see git history of the previous logo change for the procedure).
